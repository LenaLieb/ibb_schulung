# Teststrategie

Unit-Tests prüfen Suchvertrag, URL-Kanonisierung, Filter und Score. Der HTTP-E2E-Test startet den lokalen Server und prüft Suchpfad, HTML und den gebauten Datenbestand. `npm run check` führt Validierung, Build, Unit- und E2E-Tests aus. Ein fehlerhafter Test blockiert die DoD-Freigabe.

## Manueller Ersttest

Für einen ersten moderierten Usability-Test: [Teilnehmerkarte](testkarte-prototyp.md) und [Moderationshinweise mit Beobachtungsbogen](prototyp-erster-test.md). Der Test ist explorativ und ergänzt die automatisierten Prüfungen; er ersetzt weder Story-Abnahme noch fachliche Datenfreigabe.
